# ACDS - Autonomous Cyber Defense Simulator

A reinforcement-learning driven cyber defense simulator where an AI agent
learns to detect and respond to network attacks in real time.

## Architecture (planned)
- Simulation layer - network topology, hosts, traffic (Gymnasium)
- Cybersecurity layer - attack injection (DoS, port scan, brute force)
- ML/AI layer - anomaly detection + RL defender (PPO)
- Dashboard - live Streamlit visualization
